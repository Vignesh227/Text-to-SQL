t_substrate:
This table defines the properties of various substrate materials used in dyeing processes. It stores information like substrate name, code, and any relevant physical characteristics that might influence dye uptake or color appearance. This information is crucial for accurate color calculations and recipe prediction.
 
t_thread:
This table stores details about different thread types used in textile production. Information such as thread name, code, material composition, and standard color values are stored here. This data is essential for color matching and quality control processes.
 
t_recipe_dye:
This table stores the specific dye components of a recipe. It links to the main recipe table (t_recipe) and details the dyes used, their concentrations, and any specific application instructions. This allows for precise control over the dyeing process and ensures consistent color reproduction.
 
t_recipe_multi_dye:
This table likely handles recipes that involve multiple dye applications or stages. It stores information about the sequence of dye additions, concentrations at each stage, and any specific parameters for each dyeing step. This is important for complex dyeing processes where color is built up in layers.
 
t_manual_chem_format:
This table defines the format for manually entered chemical additions to a recipe. It specifies the units of measure (e.g., grams, percentages) and any formatting rules for inputting chemical data. This ensures consistency and accuracy in recording manual additions.
 
t_manual_chem_conc:
This table stores the concentration values for manually added chemicals in a recipe. It links to the 
t_manual_chem_format table to interpret the units and format of the concentration data. This allows for precise control over the chemical additions during the dyeing process.
 
t_manual_chem_text:
This table stores descriptive text associated with manually added chemicals. This might include notes about the chemical's function, specific handling instructions, or any other relevant information. This provides additional context and guidance for operators.
 
t_manual_chem_group:
This table groups manually added chemicals into categories or families. This allows for easier management and organization of chemical data, especially when dealing with a large number of chemicals.
 
t_dyehouse_setting:
This table stores configuration settings specific to a particular dyehouse or production facility. This might include information about equipment, processes, or local preferences that influence the dyeing process. This ensures that recipes are tailored to the specific conditions of each dyehouse.
 
t_dye_class:
This table categorizes dyes based on their chemical properties or application methods. This allows for easier searching and filtering of dyes, and can also be used for reporting and analysis.
 
t_recipe:
This table stores the main information about a dyeing recipe. It includes the recipe name, description, target color, and links to other tables for details about dyes, chemicals, and processes. This serves as the central repository for all recipe-related data.

t_recipe_history:
This table tracks changes made to recipes over time. It records who made the changes, when they were made, and the specific modifications. This provides an audit trail for quality control and process improvement.
 
t_thread_group:
This table groups similar threads together based on their dyeing characteristics. This is used for efficient feedback calculations, as it allows the system to apply color corrections to a group of threads rather than individually.
 
t_thread_group_details:
This table stores the specific threads that belong to each thread group. It links to the t_thread_group table and provides the details of the individual threads within each group.
 
t_material:
This table stores information about various materials used in the textile production process. This might include raw materials, intermediate products, or finished goods. This data is used for inventory management, production planning, and cost tracking.
